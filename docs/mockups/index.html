Settistics · design directions

Design ideas for the matchup page, all showing the same Sett vs Aatrox content with illustrative numbers, so only the design differs. Each one also works on a phone. Click a card to open it full size.

F

The matchup guide

E developed into one connected guide: a short matchup summary, compact setup, selectable build routes, item timing, and slot comparisons. Warm ember and gold, with a quieter overview and a more prominent build.

Try it
Switch between item-first and boots-first, select any build item, or preview a matchup with limited data.
Data
Illustrative numbers throughout. Route-specific timings and adjusted comparisons require an extended export.

E

Overview + timeline (chosen)

A simple u.gg-style build overview on top (runes, spells, start, skills, core, boots, later options), the power timeline below it, details last. The timeline shows one build order at a time, so boots-first and Stridebreaker-first games are never averaged together.

Needs
Item finish times split by build order (boots before or after the 1st item), skill order, and self-hosted rune and spell icons.

A

Cheat sheet

Everything you set in champ select on one screen, in the order you set it, drawn like the League client (rune tree, spell and item icons).

Best for
The 30 seconds in champ select. Fastest to use.
Trade-off
Little room for explanation. Looks like the u.gg family.

B

Scouting report

The matchup as a short sports write-up: a verdict headline, three things to know, then the setup, build and evidence as figures. Light, editorial type.

Best for
Understanding why. Most distinctive; no LoL site looks like this.
Trade-off
Slower to scan in champ select; the words must be generated well.

C

Power timeline

Both champions' item spikes on one 0–40 minute timeline, with gold bands where you are ahead. Keeps today's ember and bone brand. Turns vertical on phones.

Best for
Showing the matchup at a glance, using data only Settistics has (both sides' timings).
Trade-off
Needs enough games for stable timings; busy with many items.

D

Stat desk

Dense tables for every decision: pick rate, win rate, games and measured impact side by side, plus observed vs expected win rate for items.

Best for
Players who want the numbers; shows off the WPA method best.
Trade-off
Least welcoming for casual players; Lolalytics already owns this style.
